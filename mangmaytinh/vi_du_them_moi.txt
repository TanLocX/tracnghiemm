Câu 1: Giao thức nào hoạt động ở tầng Transport của mô hình OSI?

Câu 2: DNS là viết tắt của?
a. Dynamic Network Service
b. Data Name System
c. Domain Name System

=> c

Câu 3: IPv4 có tổng cộng bao nhiêu bit?
a. 16
b. 64
c. 128
d. 32
=> d

Câu 4: Thiết bị nào hoạt động ở tầng Network của mô hình OSI?
a. Hub
b. Switch
c. Router
d. Repeater
=> c

a. 21
